A C++ top-down shooter game built using Object-Oriented Programming (OOP) principles, STL, and the singleton pattern for optimal resource management. This project demonstrates my ability to apply advanced C++ techniques to create a fully functional and efficient game.

Key Features
Object-Oriented Programming (OOP): The game is designed using OOP principles, making the code modular, maintainable, and scalable.
Singleton Pattern: Implemented a TextureManager singleton to ensure textures are loaded only once, optimizing GPU usage and improving performance.
STL Containers: Utilized STL containers like std::vector and std::map for efficient data management and handling game entities.

Requirements
SFML library
A C++ compiler (e.g., Visual Studio, GCC)

To play the game download from the debug folder the .exe file and all .dll files. If windows says it may harm your computer just ignore it. To start the game press ENTER and then 1.
